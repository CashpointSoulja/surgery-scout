# Surgery Scout - viability note

## Why this is worth doing for QuantumLoopAI

The SDR role's first problem is list quality. The public cloud-telephony return is a monthly, practice-level, behavioural dataset of the exact pain EMMA treats - and it's free under the Open Government Licence. Shaping it into a call list costs nothing to run (static site, public data, no API spend) and turns every first touch from a generic pitch into a conversation about the practice's own published numbers.

## What it proves about me for the role

- I can find and work the real data source behind a sales story, not just repeat the marketing.
- I read the bad press before a prospect brings it up, and I answer it with the company's own published position plus a discovery question.
- I build the tool I'd actually use on day one, with the evidence trail a prospect can check.

## Limits of the case

Phone pressure is not buying intent, budget or authority - those come from the conversation. September is one month; a three-month average would be steadier. The return misses practices whose suppliers don't report. GPPS perception data would sharpen the tiers. All of these are stated on the page and have a known week-one build plan.

## Cost to operate

Zero marginal cost: static hosting on existing infrastructure, public data, monthly manual refresh (automatable later).
